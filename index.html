# Privacy Policy for Smart Skip **Effective Date:** July 23, 2026 Smart Skip is designed with privacy as a core principle. ## Information We Collect Smart Skip does **not collect, transmit, sell, or share** any personal information. The extension stores the following information locally on your device using Chrome Storage: - Extension settings - User preferences - Local advertisement history - Local advertisement statistics - Category insights This information never leaves your browser. ## Data Sharing Smart Skip does not: - Sell personal information - Share information with third parties - Upload browsing activity - Track users across websites - Use analytics services ## Permissions ### storage Used only to save extension settings and local statistics. ### YouTube Host Permission Used only to operate on YouTube pages to: - Detect advertisements - Skip skippable ads - Mute advertisements - Optionally speed up advertisements No browsing data is transmitted outside your device. ## Remote Code Smart Skip does not download or execute remote JavaScript or WebAssembly. All executable code is packaged within the extension. ## Changes This Privacy Policy may be updated if the extension changes. ## Contact For questions regarding this Privacy Policy: your-email@example.com
